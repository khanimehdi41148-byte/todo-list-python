# 📋 Python ToDo List

A simple command-line ToDo List application built with Python using Object-Oriented Programming (OOP). Tasks can be added, removed, displayed, saved to a CSV file, and loaded automatically when the program starts.

---

## ✨ Features

- ✅ Add new tasks
- 🗑️ Remove tasks
- 📋 Display all tasks
- 💾 Save tasks to a CSV file
- 📂 Load saved tasks automatically
- 🔢 Numbered task list
- ⚠️ Input validation

---

## 🛠 Technologies Used

- Python 3
- CSV Module
- Object-Oriented Programming (OOP)

## 🚀 Getting Started

### Clone the repository

```bash

```

### Go to the project folder

```bash
cd todo-list-python
```

### Run the program

```bash
python "1. To Do List.py"
```
